## Painel administrativo

Acesse **[o painel de edição da página inicial](https://daniel-soliz.github.io/ds-digital-portfolio/admin/)**.

O painel permite alterar textos, logo, fotos, cores, seções, serviços, projetos, botões e redes sociais; também permite reordenar ou excluir itens, enviar imagens e pré-visualizar antes de publicar.

### Primeiro acesso

1. Entre na sua conta **Daniel-Soliz** no GitHub e abra [Tokens de acesso fine-grained](https://github.com/settings/personal-access-tokens/new).
2. Crie um token com prazo de expiração, acesso **somente** ao repositório **ds-digital-portfolio** e permissão **Repository permissions → Contents → Read and write**.
3. Cole o token **somente na página do painel**, clique em **Conectar com segurança**, altere o conteúdo e use **Publicar alterações**.
4. A publicação é feita no arquivo content.json do repositório e sincroniza os metadados do index.html. O GitHub Pages pode levar alguns minutos para refletir a atualização.

**Segurança:** não coloque tokens ou senhas no código, em issues, mensagens ou arquivos do projeto. O painel não armazena o token; ele é usado em memória e enviado apenas para api.github.com. Sem token autorizado, não é possível publicar. A URL /admin/ é pública (por ser GitHub Pages), mas a gravação é protegida pela autorização da conta GitHub.
